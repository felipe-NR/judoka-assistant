Onde roda

A VM não abre porta na OCI: o tráfego público entra pelo Funnel, que dá HTTPS e entrega a 127.0.0.1:8010; ali o bloqueio por país e o rate limit agem antes de qualquer chamada a provedor. O GitHub Actions entra na tailnet como nó efêmero com tag:ci e a chave dele só roda judoka-deploy <commit>, que recusa commit fora do main. A API chama a OpenAI pela Decisions API (guardrail) e pela Responses API (resposta); com JUDO_CHAT_PROVIDER=anthropic, as duas chamadas vão à Messages API. Detalhes em docs/operacao/deploy.md.
